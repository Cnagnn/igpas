How it works

Three steps. No build, no cloud, no accounts.

1 · Install

Install Tampermonkey, then the userscript. It never draws anything on the live race view — only its own clearly-marked study panels (and, on request, pre-race Setup/Strategy estimates); the calculators live here.

2 · Connect

Open the Command Center in one tab and iGP Manager in another — they link over a local storage mailbox.

3 · Study

Enter your numbers, read the projections and recommendations, save setups per circuit.

⚠ A study tool, not a race aid.

I.G.P.A.S performs zero automation, makes zero network requests, never renders an interface on the live race view (pre-race Setup/Strategy estimates are read-only panels added at the owner's request), and never touches game elements during a race. Use it for analysis, practice and post-race review — and please respect the iGP Manager Terms of Service.
